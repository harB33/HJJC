# HJJC Coffee Store ☕

[![PHP Version](https://img.shields.io/badge/PHP-8.2%2B-777BB4?style=for-the-badge&logo=php&logoColor=white)](https://www.php.net/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-v4-06B6D4?style=for-the-badge&logo=tailwind-css&logoColor=white)](https://tailwindcss.com/)

HJJC is a premium, high-fidelity e-commerce platform dedicated to delivering an unparalleled coffee experience in the Philippines. Built with a focus on **aesthetic excellence** and **seamless user experience**, HJJC redefines the standard of online coffee ordering.

---

## ✨ Features

### 🛍️ Premium Shopping Experience
- **Interactive Product Catalog:** A visually stunning showcase of world-class coffee blends, from robust classics to nuanced single-origins.
- **Dynamic Cart System:** Real-time cart management with a sleek, glassmorphic UI.
- **Secure Checkout:** Streamlined address forms and order processing.

### 👤 User & Account Management
- **Personalized Accounts:** Secure registration and login system with "Remember Me" functionality.
- **Order Tracking:** View past and current orders with detailed status updates.

### 🛡️ Administrative Power
- **Inventory Management:** Comprehensive admin dashboard to add, update, or remove products.
- **Product Input System:** Intuitive interface for managing stock and product details.

### 🎨 Modern Design Language
- **Glassmorphism & Micro-animations:** A premium feel with backdrop blurs, smooth transitions, and hover effects.
- **Fully Responsive:** Optimized for both mobile and desktop views using Tailwind CSS v4 and DaisyUI.
- **Visual Excellence:** High-quality video backgrounds and custom-curated color palettes.

---

## 🛠️ Technology Stack

- **Core:** PHP 8.2+
- **Database:** MySQL
- **Frontend:**
  - Tailwind CSS v4 (Alpha/Edge)
  - DaisyUI v5
  - Vanilla JavaScript
- **Libraries:**
  - **PHPMailer:** For robust email notifications and confirmations.
  - **mPDF:** Generating high-quality PDF invoices and receipts.
- **Architecture:** Custom Front Controller pattern for clean URL routing.

## 🚀 Getting Started

### Prerequisites
- **XAMPP / WAMP / MAMP** (Apache & MySQL)
- **PHP 8.2+**
- **Composer** (for dependency management)

### Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/your-username/HJJC.git
   cd HJJC
   ```

2. **Install PHP Dependencies**
   ```bash
   composer install
   ```

3. **Database Setup**
   - Import the SQL file located in `/database` (if provided) into your MySQL instance.
   - Configure your credentials in `config/db.php`.

4. **Configuration**
   - Ensure `config/config.php` has the correct `BASE_URL` for your local environment.

5. **Run the App**
   - Move the project to your `htdocs` folder.
   - Access the app via `http://localhost/HJJC/public/` (or your configured local URL).
